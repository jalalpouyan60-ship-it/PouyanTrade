# پویان‌ترید — نسخه 1.0

نسخه اولیه اندروید برای تحلیل DOGEUSDT.

امکانات:
- دریافت کندل‌های 1 ساعته از API عمومی Binance
- EMA20، EMA50 و RSI(14)
- وضعیت LONG / SHORT / WAIT
- انتخاب اهرم 10× یا 20×
- رابط فارسی
- بدون کلید API و بدون اجرای خودکار معامله

برای ساخت APK، پروژه را در Android Studio باز کنید و از Build > Build APK(s) استفاده کنید.

هشدار: این ابزار سیگنال قطعی یا تضمین سود نیست؛ مخصوصاً اهرم 20× ریسک بالایی دارد.
